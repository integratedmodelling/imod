## Reading the packets

**F = foundational:** needed to state common observations coherently. **U = useful:** broad recurring need after supports settle. **D = deferrable:** specialized catalogue, threshold or theory detail. F does not mean already approved. Each row specifies a use case, category and dependence, alignment/dependencies, evidence and a discriminating acceptance pair. Those pairs are proposed semantic tests, not executed parser/reasoner results.

`S` means non-agentive substantial/Subject (arity 0); `Q` dependent quality (arity 1); `P` dependent process (arity 1, native bearer/participants must be chosen); `E` bounded event (independent occurrence); `C` detected configuration (no inherited native bearer); `I/A/Rm/Rl` identity, attribute, realm and role predicates. `Rel` is a binary observable connection with typed substantial endpoints and both independent axes specified. Domain ownership supplies none of these bearers automatically. Declaration keywords supply generic category ancestry; listed domain parents indicate genuine specialization, not redundant root-parent clauses.

New quality names in this packet are working labels, not a commitment to duplicate existing generic compositions. Distinct dimensions remain separate. Use `equals` only after exact equivalence is demonstrated; a conventional synonym is not sufficient. All Q/P observations need explicit support, interval and reference conventions. Where a native bearer is unresolved, the proposal remains blocked rather than receiving an invented one. Process participants and parameters are not automatically its native bearer. No blanket `creates`/`affects`, formal mereology, causal inference or automatic recognition rule is proposed.

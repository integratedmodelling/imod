## Shared semantic and implementation checks

1. **Relationship axes:** abstract SocialRelation leaves both unspecified, WorkRelation inherits structural only, concrete EmployeeOf is structural directed; ProvidesSupportTo is functional directed. Swapping directed endpoints changes meaning. Neither an abstract omission nor a method name supplies a silent default. A future truly unordered mutual-recognition bond must be explicitly justified; no redundant bond is invented here.
2. **Native bearer:** HouseholdSize belongs to household, WorkTime to person, GDP to the proposed accounting aggregate, trust to respondent, nonmonetary importance to the valued substantial.
